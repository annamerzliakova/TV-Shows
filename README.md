
Welcome to my project! This is a clean, lightweight web application disigned for discovering and  searching  movies. Here I’m collecting the best places for visiting.



The application features a curated database of **9 iconic movies**, and users can find any film they want instantly by typing its title into the interactive search bar.

---

## 🔥 Features
* **Instant Filtering:** The movie list updates in real-time as you type in the search bar.
* **Responsive Layout:** Beautiful grid system that works flawlessly on desktop, tablet, and mobile screens.
* **Clean UI:** Elegant movie cards with posters, genres, and descriptions.

---

## 🛠 Tech Stack
This project was built using core web technologies:
* **HTML5** — Structured the search interface and movie database layout.
* **CSS3** — Styled the application with modern layouts, smooth hover transitions, and responsive design.
* **JavaScript** — Powering the dynamic string search and filtering logic.

---

## 🍿 Included Movies (Database)
The search functionality natively supports the following **9 films**:
* **Interstellar** — Sci-Fi / Drama
* **Inception** — Action / Sci-Fi
* **The Dark Knight** — Action / Crime
* **Pulp Fiction** — Crime / Drama
* **Fight Club** — Drama
* **The Matrix** — Sci-Fi / Action
* **Forrest Gump** — Romance / Drama
* **The Shawshank Redemption** — Drama
* **Spirited Away** — Animation / Fantasy
